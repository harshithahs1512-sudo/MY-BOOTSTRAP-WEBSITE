# Creative Hub – My Bootstrap Website

This is a simple shopping website I created while learning Bootstrap 5. I tried using different Bootstrap components and JavaScript to make the website interactive and responsive.

## Features

- Navigation bar with Home, Shop, Cart and Contact.
- Welcome section with an Explore Products button.
- Product cards for Headphones, Smart Watch and Wireless Speaker.
- Add products to the shopping cart.
- Increase and decrease product quantities.
- Automatic total price calculation.
- Clear Cart option.
- Basic checkout functionality.

## Technologies Used

- HTML
- CSS
- Bootstrap 
- Bootstrap Icons
- JavaScript

## What I Learned

While creating this project, I got to practice:

- Using Bootstrap classes.
- Creating responsive layouts.
- Working with Bootstrap cards and navigation bars.
- Using JavaScript functions and arrays.
- Adding and removing items from a shopping cart.
- Updating content using DOM manipulation.
